# MiColección Cine — Entrega 1

Prototipo estático navegable con Node.js y Express.

## Ejecutar

```bash
npm install
npm start
```

Abre http://localhost:3000

## Rutas

| Ruta | Página |
|---|---|
| `/` | Inicio |
| `/login` | Iniciar sesión (simulado) |
| `/contacto` | Contacto (envío simulado) |
| cualquier otra | 404 |

## Estructura

```
server.js
package.json
views/        index.html, login.html, contacto.html, 404.html
public/
  css/style.css
  js/main.js
HISTORIAS_DE_USUARIO.md
```
